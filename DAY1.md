# Schedula Backend — Day 1

NestJS starter for the Schedula appointment booking system (Backend Internship — Day 1).

## Tech stack

- NestJS + TypeScript
- PostgreSQL (planned for later days)
- Hoppscotch / Postman for API testing
- Git & GitHub

## Run locally

```bash
cd schedula
npm install
npm run start:dev
```

App URL: [http://localhost:3000](http://localhost:3000)

Expected response: `Hello World!`
